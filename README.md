# Software Engineering Assignment (WebApp)

## Overview
This is a group project for the Software Engineering module developed in C# by a team of 3 students. While the application is built together as a team, each student submits an individual report detailing their own contributions.

## Team & Roles

## How to Run the Project
1. Clone this repository to your computer.
2. Open the solution file (`.sln`) in Visual Studio or open the folder in VS Code.
3. Set up the local database if required.
4. Build and run the application.

## Team GitHub Rules
- Create a new branch for each feature or bug fix before writing code.
- Write clear commit messages describing what you changed.
- Use Pull Requests to merge code into `main`.
- Keep code clean: proper indentation, no extra blank lines, no commented-out old code, no unused variables, and brief comments explaining each section.

## Key Milestones & Marking Breakdown
- Week 4 Progress Review: 5 marks
- Week 8 Progress Review: 5 marks
- Case Study & Requirements: 10 marks
- Software Design (Wireframes, ERD, MVC): 20 marks
- Software Implementation (Code & Quality): 20 marks
- Testing (Manual tests & bug fixes): 15 marks
- Software Maintenance Plan: 5 marks
- Individual Contribution & GitHub Evidence: 10 marks
- Individual Reflection: 10 marks

## Final Submission (Canvas)
1. Individual Report (`.docx` or `.pdf`, max 15 pages, do not zip).
2. Completed C# Software Application (`.zip` file).
